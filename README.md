DOAX Venus Vacation 的原生建模精度较低。针对这一问题，此前已有开发者制作过高多边形模组，效果表现出色，但据我了解，这类现有模组与已有的服装模组兼容性不佳。为了打造一款兼容性更强的高多边形模组，我修改了渲染管线，通过加入外壳着色器（hull shader）和域着色器（domain shader），实现了游戏运行时实时将所有角色模型升级为高多边形效果。

## 模组特性

### 优点

1. 单模组即可统一提升所有角色的模型精度，无需逐个替换角色资源
2. 理论上兼容绝大多数现存服装模组

### 缺点

1. 传统第三方高多边形模组可针对每个角色模型进行定制化精细调整；本方案采用通用曲面细分算法，仅依托三角形面片本身的数据生成细分结果，最终模型细节质量略低于定制高模。
2. 当前模组测试样本较少，若你在使用过程中遇到异常问题，欢迎提交反馈，我会尽可能进行修复。

## 已知冲突模组

下列模组会替换角色的**头部/身体网格**，与本模组同时启用时会出现脸部错位等渲染异常。原因见下方说明。

| 模组 | 现象 | 规避方法 |
|---|---|---|
| `Skins_V4/Momiji_2_Mai_TEDDY_v1.4_STEAM` | 部分角色脸部错位、轮廓撑出头发（耳朵外露），五官本身正常 | 停用该模组；或按 `Ctrl+Q` 把它的 `$var1` 切到 1（关闭替换） |

### 冲突原因

本模组的皮肤管线在皮肤着色器上 `handling = skip` 跳过游戏原始绘制，然后靠 `draw = from_caller`
重放本 draw 自己的原始网格。而这类模组通过 `[TextureOverrideHead]` 之类的节，在
`checktextureoverride` 阶段把自己的网格换上去并绘制了一次。

第三方模组通常会在绘制结束后把 `vb0`/`ib` 还原成游戏原版，因此 `from_caller` 重放时绑定的是
**游戏原始网格**——也就是说：

- 第三方模组替换的网格（例如 Mai 的头）由它自己绘制，**不会经过本模组的细分管线**
- 本模组细分的始终是**游戏原版网格**，并且会把它**额外再画一遍**

两者叠加即为错位、轮廓变大的来源。本模组目前只在 CostumeCustomizer 的身体网格上通过
`[TextureOverrideTessBodyMark]` 做了门控，第三方模组的替换无法被识别，故有此限制。

如果你遇到其他会替换网格的模组触发同类问题，欢迎提交反馈。
